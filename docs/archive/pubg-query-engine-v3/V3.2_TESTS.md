## Evidence Safety Cases

- Pickup 3, shots 0 → `ROCKET_UNUSED`.
- Shots > 0, hits 0 → no `ROCKET_HIT`.
- Attack ID + vehicle ID + destroy + correlated kills → eligible for `ROCKET_VEHICLE_MULTI_KILL`.
- Only close timestamps or a shared vehicle ID without causal attack linkage → no multi-kill claim.
- Raw telemetry is not supplied to planner/LLM or platform renderer.
