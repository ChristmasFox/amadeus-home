# Lab / Gate actions requiring separate approval

This checklist records actions outside the source/tests/docs authorization for
the Lab Memory Core and dual-release engineering Goal. A CLI `--approval-ref`
is an audit identifier; entering one does not itself grant operational
authorization.

| Action | Direct effect | Preconditions and recovery | Status |
| --- | --- | --- | --- |
| Probe the configured Embedding endpoint | `openclaw memory status --deep --agent main` performs provider-readiness probing; an explicit synthetic `/v1/embeddings` probe sends a request to the configured provider. Either may incur usage charges. The deep status reports runtime readiness; the explicit request verifies response shape and dimension. | Approve the provider probe and cost. Use synthetic text only. Do not proceed to a reindex if the returned dimension does not match the index contract. | `AUTHORIZED; COMPLETED 2026-10-15: HTTP 200, 1024 finite dimensions, 32 input tokens` |
| Refresh or rebuild the Lab memory index | `openclaw memory index --agent main` performs the normal incremental index operation and writes the derived SQLite vector/FTS index and embedding cache for changed inputs; it may issue billable Embedding requests. `openclaw memory index --force --agent main` rebuilds the full index and may issue many requests. The pre-write baseline was `dirty=true`, 2 indexed files versus 3 scanned; post-rebuild status was 3/3 files and `dirty=false`. | First create and verify a protected online SQLite backup and record current index identity. Approve the provider probe separately; confirm model and dimension. Afterward check FTS, paraphrase retrieval, hybrid results, incremental refresh, `dirty=false`, and restart persistence. Preserve newer writes; do not restore an old whole database over them. | `PRIORLY AUTHORIZED FULL REBUILD PASSED; incremental refresh/restart remain open and are not authorized by the current source-only scope` |
