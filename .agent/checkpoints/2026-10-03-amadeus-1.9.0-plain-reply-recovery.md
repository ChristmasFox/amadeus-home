## Cause

At 14:22, the private WhatsApp VPS-status turn produced ordinary assistant text.
The strict DeliveryEnvelope decoder expected JSON v2, classified that natural
text as malformed structured output, and sent the generic
`回复格式异常，已记录，请稍后重试。` response. The runtime logged the same
invalid-output warning twice because two plugin registration callbacks observed
the same run; the user-facing delivery itself was one text send.

## Fix

Amadeus 1.9.0 recovers safe plain text for external user turns as one typed text
part. The recovery is fail-closed for protocol-shaped objects, JSON-looking
output, paths, fenced payloads, MEDIA directives and control tokens. Inbound
voice still requires its typed voice contract, and trusted internal origins stay
silent. A regression covers the plain VPS-status style response and retains the
malformed protocol cases.
