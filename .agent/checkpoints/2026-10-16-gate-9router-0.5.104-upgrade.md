## Rollback

The old image remains on the OrbStack machine. To restore the pre-upgrade
SQLite and configuration, stop only the Router service, decrypt the archive to
`/srv`, then start the old image with a Compose override:

```sh
orb -m pubg-saas-m2-clean -u root docker compose --project-name 9router \
  --env-file /srv/pubg-saas-9router/.env \
  -f /srv/pubg-saas-9router/docker-compose.yml stop 9router
age -d -i ~/.local/share/pubg-saas-backup/age-identity.txt \
  /Volumes/Avalon/backups/operation-skuld/9router/gate-local-0.5.104-preupgrade-20261016T103944Z/pubg-saas-9router-full.tar.gz.age \
  | orb -m pubg-saas-m2-clean -u root tar -xz -C /srv
orb -m pubg-saas-m2-clean -u root bash -lc '
  docker compose --project-name 9router \
    --env-file /srv/pubg-saas-9router/.env \
    -f /srv/pubg-saas-9router/docker-compose.yml \
    -f <(printf "services:\n  9router:\n    image: local/9router-saas:from-83bb76b-20261014\n") \
    up -d --no-build --no-deps 9router
'
```
