# Amadeus 1.5.2 M204 accurate power sampler

Date: 2026-09-24

## State

- Live CasaOS is on the 1.5.1 image and its Longbridge market session/quote plus host tools pass.
- The host status power field is still degraded because the user LaunchAgent cannot invoke
  macOS `powermetrics`, and the old command used options removed by the current macOS build.
- No power number from CPU load is accepted as a measurement.

## Change

- Add `infra/macos/machostagent_power.py`, a fixed root-only sampler using current plist output from
  `powermetrics --samplers cpu_power,gpu_power,ane_power,thermal -A -n 1 -i 1000 --format plist`.
- Atomically publish a bounded snapshot at `/var/run/amadeus-machostagent-power.json` and reject
  stale samples in the user agent after 30 seconds.
- Expose CPU/GPU/ANE/SoC mW, `powerWatts`, sample duration, `scope=soc`, and explicit accuracy metadata.
- Add `--accurate-power` to the installer for the one-time root LaunchDaemon authorization.

## Verification

- `python3 -m unittest infra.macos.test_machostagent -v` passed (5 tests).
- Python compile, installer shell syntax, plist lint, and `git diff --check` passed.
- `VERSION=1.5.2` and release notes validation passed.

## Next action

Commit/push and deploy 1.5.2, then run `infra/macos/install-machostagent.sh --apply --accurate-power`
on M204 with the user's local authorization. Only after a fresh supported snapshot should the
owner tool report measured SoC watts. Exact wall-input watts still require an external power meter.
