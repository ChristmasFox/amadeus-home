# Amadeus 1.8.7 silent protocol guard checkpoint

Date: 2026-10-02 (Asia/Shanghai)

## Change

Release `1.8.7` treats a control-token-prefixed uppercase sentinel as typed
protocol silence in the DeliveryEnvelope decoder. The WhatsApp final text
adapter also rejects any control token immediately before provider send. This
closes the path that could expose an internal silent response such as a
control marker followed by a no-reply sentinel as user-visible WhatsApp text.
Normal user text and typed DeliveryEnvelope v2 parts remain unchanged.
