## Change

A successful ordinary `image_generate` now completes the Amadeus typed
settlement first, retaining the trusted generated attachment, Asset Registry,
DeliveryEnvelope, 9Router image route, and one channel image send. The overlay
then removes `attachments` and `mediaUrls` from the native wake parameters and
falls through to the pinned native `task_completion` / Completion Agent
continuation. Native status/result/completion metadata remain available, so the
requester task reaches native terminal state and the natural completion reply is
restored without a second image send.

The failure branch and all unrelated ordinary text, voice/TTS/ASR,
`amadeus_image_upscale`, upscale document, reference-image, and other
DeliveryEnvelope paths remain unchanged. `image-caption.ts` was not modified.
