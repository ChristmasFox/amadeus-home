# Amadeus 1.8.6 native image task timeout checkpoint

Date: 2026-10-02 (Asia/Shanghai)

## Change

Release `1.8.6` sets `agents.defaults.mediaModels.image.timeoutMs` from
`180000` to `120000` in the canonical OpenClaw configuration template. The
running `/home/node/.openclaw/openclaw.json` now reports `timeoutMs: 120000`
for the image model.

This release includes the 1.8.5 completion recovery already deployed in the
image: caption enrichment has a 120-second semantic deadline, and the native
completion overlay invokes the typed Amadeus attachment fallback when a queued
native handoff reaches its 120-second deadline. Kurisu caption wording remains
unrestricted by an Amadeus character limit.
