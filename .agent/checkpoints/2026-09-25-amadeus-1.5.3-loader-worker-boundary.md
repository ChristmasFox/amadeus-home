# 2026-09-25 — Node worker vs ffmpeg glibc boundary (source revision)

- The first real WhatsApp voice note reached ASR/Agent/TTS but outbound PTT failed because ffmpeg inherited the Gateway's private Longbridge glibc `LD_LIBRARY_PATH` and exited 127. An isolated command using `/lib/ld-amadeus.so --library-path ... node.glibc` appeared to preserve Longbridge and ffmpeg; image `local/openclaw-amadeus:git-7651dd07d429-20260925052605` passed the initial narrow image fixture.
- Explicit candidate apply of that image took protected OpenClaw checkpoint `/DATA/AppData/openclaw/backups/amadeus-openclaw-20260925052705`, then failed **before canonical Compose update** during the pinned CLI preflight. OpenClaw's SQLite read-only worker is spawned via `process.execPath`; invoking Node through the loader directly changed that path to the loader, which tried to execute a `.js` file as ELF (`invalid ELF header`). Current production remained the prior healthy candidate image `local/openclaw-amadeus:git-109d4590c6b4-20260925043803`, VERSION=1.5.2, with the known PTT failure. No second Gateway or release notification was created.
- Additional isolated reproduction showed `/bin/sh`, `/usr/bin/env`, `/bin/bash` and `/usr/bin/ffmpeg` all exit 127 if directly spawned under the leaked private library path, so a shell script cannot sanitize it before dynamic loading.
- Source now restores Node's original private-glibc wrapper to preserve `process.execPath` and SQLite worker spawn. It installs a narrow `/usr/bin/ffmpeg` and `/usr/bin/ffprobe` Node-based executable wrapper in the immutable image; that interpreter can start with the private glibc, removes `LD_LIBRARY_PATH` only for the real Debian media child, and passes through stdio and exit status. No global transport or Agent behavior is changed. The image fixture now requires native Longbridge import, Node worker self-spawn, real MP3 -> Ogg/Opus ffmpeg child conversion and ffprobe child. Syntax, architecture, session-isolation and secrets tests passed; this revised image has **not yet** been built/applied or tested on a genuine WhatsApp resend.
