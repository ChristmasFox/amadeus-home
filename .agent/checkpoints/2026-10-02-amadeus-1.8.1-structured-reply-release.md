## Change

Malformed external structured replies now settle as a bounded visible fallback:
`回复格式异常，已记录，请稍后重试。` Literal control characters inside JSON
strings are repaired safely. Raw malformed model output is not echoed or logged;
only bounded run correlation metadata is recorded. Trusted internal origins remain
silent. The existing `nine_router/arthur-combo` agent route remains authoritative;
web search provider selection is a separate retrieval concern.
