# Amadeus 1.8.8 image completion fallback checkpoint

Date: 2026-10-03 (Asia/Shanghai)

## Incident and change

The private WhatsApp image task generated and registered its image asset, but
the native Completion Agent continuation timed out. The typed fallback then
created a completion run that could not reclaim the already-claimed asset and
also overwrote the private session route. The user received no image and a
later follow-up could be treated as a completion response.

Release `1.8.8` keeps the runtime-owned media completion claim available until
settlement, lets an unprepared fallback run transfer the claim from a timed-out
native run, and starts the fallback without binding the private session route.
The generated attachment is therefore delivered once while later messages
continue through their own inbound runs.
