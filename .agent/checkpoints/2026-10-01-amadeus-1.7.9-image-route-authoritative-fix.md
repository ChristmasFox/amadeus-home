## Phase 1 — authoritative native boundary

A version- and SHA-pinned OpenClaw 2026.9.4 overlay now runs inside the existing
native `image_generate` tool after action/schema parsing and before model
selection or task creation. It ignores the model-authored value, fails closed
if the configured image primary is absent, and selects only that operator
primary. The same `model: undefined` and configured route are captured by the
existing detached task closure. No second tool, wrapper Agent, planner, or
provider stack was introduced.

The pinned native tool schema retains the optional `model` input for compatibility
but tells the Agent it is ignored; concrete GPT Image hints/defaults were removed
from Agent-visible schema and tool descriptions. Existing `before_tool_call`
blank-sentinel policy remains defense-in-depth and emits safe JSON routing facts.

The OpenClaw image runtime verifies its resolved candidate equals the configured
logical route; the OpenAI-compatible adapter verifies the final provider/model
pair immediately before request construction. A mismatch throws bounded
`image_route_invariant_violation`. Routing diagnostics carry task/run/tool IDs,
logical route, bounded provider status, and override booleans only—never prompt
or media content.
