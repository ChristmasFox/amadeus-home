`longbridge_unavailable` instead of using a provider fallback.

macOS collectors, owner-only plugin tools, and independent degraded power
telemetry. No `exec` route, arbitrary command parameters, or account/trading
tool is registered.

## Follow-up source correction

Longbridge's current public-client OAuth flow requires S256 PKCE. The operator
helper now stores a short-lived verifier outside Git, includes `scope=3` and the
PKCE challenge in the authorization URL, requires the complete callback URL on
exchange, validates the returned state, and deletes the request file after a
successful exchange. No token or verifier is printed or committed.
