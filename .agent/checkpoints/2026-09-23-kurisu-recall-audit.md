This incorrectly counted cache assets, package code, and other unrelated files. Those values are invalid and must not be used as evidence that sessions or transcripts were migrated.

The primary OpenClaw session/transcript store is `config/agents/main/agent/openclaw-agent.sqlite`; the current database counts above are the relevant runtime evidence.
