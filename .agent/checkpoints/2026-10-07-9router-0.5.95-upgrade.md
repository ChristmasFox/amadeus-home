restarts only the 9Router service if post-switch verification fails. For a
manual rollback, on `nyannyan` copy
`/DATA/AppData/9router/backups/router-upgrade-20261007T065751Z/docker-compose.yml`
back to `/var/lib/casaos/apps/9router/docker-compose.yml`, then run
`docker compose up -d --no-build 9router` from that app directory. The prior
image archive and checkpointed SQLite database remain available; no database
restore was performed during this upgrade.
